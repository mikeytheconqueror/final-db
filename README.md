Репозиторий final-db представляет собой реализацию небольшой системы регистрации и учёта посылок с использованием Go и SQLite. 
Проект демонстрирует работу с базой данных, реализацию CRUD-операций, а также инкапсулирование логики через сервис и хранилище.

Описание

Приложение реализует управление посылками, хранящимися в SQLite-базе:
-Регистрация посылки
-Изменение адреса
-Обновление статуса
-Удаление (только для зарегистрированных)
-Получение списка посылок клиента

Основная логика разделена на:
-Сервис (ParcelService) — содержит бизнес-логику;
-Хранилище (ParcelStore) — операции с БД;
-Тесты — автоматическое покрытие основных операций.

Как собрать и запустить.
```bash
git clone https://github.com/mikeytheconqueror/final-db.git
cd final-db
git checkout second-iteration
```
Установить зависимости
```bash
go mod download
```

Создать базу данных и таблицу
В корне проекта создайте SQLite-файл и таблицу:
CREATE TABLE IF NOT EXISTS parcel (
    number INTEGER PRIMARY KEY AUTOINCREMENT,
    client INTEGER NOT NULL,
    status TEXT NOT NULL,
    address TEXT NOT NULL,
    created_at TEXT NOT NULL
);

Запустить приложение
```bash
go run .
```
Приложение выполнит демонстрацию:
-Регистрация новой посылки
-Изменение адреса
-Изменение статуса
-Попытка удаления (по статусу)
-Вывод списка посылок для клиента

Тестирование

Проект содержит тесты для ключевых операций:
-TestAddGetDelete — проверяет добавление, получение и удаление
-TestSetAddress — проверяет изменение адреса
-TestSetStatus — проверяет изменение статуса
-TestGetByClient — проверяет выборку по клиенту

Запустить тесты:
```bash
go test ./...
```

Логика работы
Основные сущности
-Посылка (Parcel) — структура с полями:
-Number — номер/идентификатор
-Client — идентификатор клиента
-Status — статус (registered, sent, delivered)
-Address — адрес доставки
-CreatedAt — время регистрации

Статусы используются для ограничения операций (например, удаление возможно только в registered).
